# Documentation

Store project documentation here, including:

- Official data catalogue and source citation
- Survey questionnaires and manuals
- Codebooks and variable labels
- Sampling and fieldwork documentation
- Data-use and licensing notes
- Project data dictionary
- Data quality assessment notes
- Indicator definitions and calculation rules

Keep a note of the exact source URL, download date, file names, and version for every dataset obtained. Do not assume a variable's meaning from its name alone; verify it in the official documentation.
