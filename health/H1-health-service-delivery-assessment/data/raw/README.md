# Raw data

Place original, unmodified source files in this directory only when the data licence and repository privacy requirements permit redistribution.

Before adding any file, verify:
- The official source and version
- The applicable licence or data-use terms
- Whether the file contains confidential or personally identifiable information
- Whether redistribution through a public GitHub repository is permitted

If redistribution is not permitted, keep the data locally and document the official download instructions here. Never commit sensitive microdata.
